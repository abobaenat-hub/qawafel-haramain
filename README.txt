قوافل الحرمين - النظام الداخلي
================================
هذه نسخة مراجعة داخلية قبل إضافة الوكلاء والعملاء.

الصفحات:
- internal.html : المركز الداخلي / لوحة المتابعة
- admin.html    : إدارة الرحلات والبرامج
- pilgrims.html : إدارة المعتمرين والحجوزات والأقساط
- financial.html: الإدارة المالية والمصروفات والأرباح

النشر:
1) ارفع الملفات إلى نفس مستودع GitHub.
2) افتح: /internal.html
3) سجل الدخول بحساب الإدارة.
4) افحص كل قسم وسجل الملاحظات قبل الانتقال إلى نظام الوكلاء والعملاء.

العملة: الدينار العراقي فقط.
